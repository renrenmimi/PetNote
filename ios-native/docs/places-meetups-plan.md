# 地点、打卡、聚会：迁移方案（分三段）

依据是对旧版网页、服务端和规则的逐文件盘点（2026-09-23），不是凭印象。

## 现状

- **旧版有**：
  - 地点：列表（按类别筛；按附近、评分、评价数、最新排序；按名字搜），详情（照片、评价、打卡、在这里办的聚会、导航链接），添加地点，写评价（评分、三个小项、标签、最多 3 张照片）。
  - 打卡：必须带照片，可选宠物，每人每天一次。
  - 聚会：列表（附近、本周、我的、按物种筛），详情，报名，退出，发起人取消，结束后评分，创建，编辑（含封面图、私密地址）。
- **Swift 版有**：宠物主页上显示这只宠物的打卡。服务端函数的名字常量已登记。其余都没有：没有「地点」「聚会」两个 Tab，没有定位，没有地图。
- **规则**：地点、聚会、评价、打卡**客户端都不能直接写**，全部经服务端函数；客户端只能读，以及删除自己的评价或打卡。

## 卡在哪里

| 能力 | 需要什么 | 测试项目 `petnote-devtest` 现在有没有 |
| --- | --- | --- |
| 读地点、聚会、评价 | 只读 Firestore；规则已发布 | 有，但**测试项目里没有地点和聚会数据** |
| 报名、退出、取消聚会 | `joinMeetupCallable` 等 5 个函数，外加两个通知触发器 | 没部署 |
| 打卡、评价照片、地点照片、聚会封面 | 上传图片 → 测试 Cloudinary | 没有（等你开账号，见 `test-cloudinary-setup.md`） |
| 添加地点、发起或编辑聚会 | 地址搜索和坐标反查 → Geoapify（服务端密钥） | **没有，也有意不放**：测试项目不持有 Geoapify 密钥是之前的决定 |
| 「附近」排序、设置里的「我的位置」 | iPhone 定位权限；把坐标变成城市还要 Geoapify | 没有 |
| 聚会到点自动结束 | 定时任务 `autoCompleteMeetups` | 测试部署入口拒绝定时任务。客户端打开详情时会自己调 `checkMeetupStatusCallable` 兜底 |

## 分三段

### 第一段：不需要新授权，本机模拟环境就能做到 ③

- 加「地点」「聚会」两个 Tab（旧版底部导航就是 首页 / 地点 / 发布 / 聚会 / 我的）。
- 地点列表：类别筛选；按评分、评价数、最新排序；名字搜索。
- 地点详情：照片、评价列表、打卡列表、在这里的聚会；「导航」打开苹果地图，不用内嵌地图。
- 聚会列表：本周、我的、按物种筛。聚会详情：报名、退出、发起人取消。
- 模拟环境里所有函数都在跑，报名和退出能走真实的服务端逻辑。种子数据需要加几个地点和聚会。
- 「附近」这一段不做，按钮也不放。

### 第二段：等测试 Cloudinary（你开账号）+ 批准部署相应函数

- 打卡（必须带照片）、写评价（可带照片）、给地点加照片、聚会封面。
- 要部署到测试项目的函数到时候单独列清单，和媒体函数那份一样逐个说明副作用。

### 第三段：等你对 Geoapify 做决定

- 添加地点、发起和编辑聚会（地址搜索、坐标反查）、「附近」排序、设置里的「我的位置」。
- 选项一：测试项目也开一个**独立的** Geoapify 免费账号，不复制生产密钥。
- 选项二：这几项只在模拟环境验证到 ③，不上测试云。
- 定位权限需要在 Info.plist 加一句用途说明，文字要你确认，因为它会出现在系统弹窗里。

## 这一轮

先做第一段。第二、三段只列清单，不部署、不申请密钥。
