# 真机验收：必须真人做的事

设备到 2026-09-19 为止一直是 `unavailable`，所以下面这些一件都没做过。

这份清单只列**我做不了、必须你动手**的。其余全部自动化：装机、启动、登录、
滚动、点赞、截图、以及事后到后端核对，都不需要你参与。

## 开始前（约 1 分钟）

1. iPhone 插上线，解锁。若弹出"信任此电脑"，点信任。
2. 临时把自动锁定关掉：**设置 → 显示与亮度 → 自动锁定 → 永不**。
   （设备锁屏会让自动化中断，这是整个流程最常见的失败原因。验收完记得改回去。）

就这两步。之后我会自己装包、启动、用种子账号登录。

**不会碰你的真实账号，不会退出你已登录的任何东西，不会截其他 App 的屏。**
登录用的是 `accept-a@example.com` 这类种子账号。

## 中途需要你点的（约 2 分钟，集中在一起）

这几件事 iOS 在技术上就不允许程序代劳，不是我偷懒：

| 做什么 | 为什么必须是人 |
| --- | --- |
| 在评论框里点一下，用中文输入法打两行字 | **iOS 上键盘无法由程序唤起。** 中文候选栏的高度只有真键盘才有 |
| 从屏幕左边缘往右拖到一半，停住，再放回去 | 可中断的返回手势没有程序接口 |
| 拖到一半后松手完成返回 | 同上 |

我会在需要的时候一次性提示你，不会反复打断。

**我不会承诺"只需要你点一次"** —— 上面是三个动作，真实次数取决于当时的结果。
如果某一项没通过需要重做，我会先说清楚为什么，再问你要不要再来一次。

## 结束后

把自动锁定改回原来的设置。

## 你可以自己核对的一件事

每张截图的左上角都会显示一行小字，比如 `EMULATOR · petnote-test`。
那是 App **实际连上**的后端，不是它打算连的。
如果任何一张截图上出现了 `petnote-a9dac`，那就是连到生产了，
请直接告诉我 —— 不过 App 在那种情况下会先自己崩掉，不会走到截图这一步。
